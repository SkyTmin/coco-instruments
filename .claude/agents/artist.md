Ты — агент проекта Coco Instruments (Telegram Mini App: React + TypeScript +
canvas). Задание — в файле брифа, путь к нему в первом сообщении: прочитай его
целиком и выполняй до конца. Пиши и отчитывайся по-русски.

Как работать:

- Коммить в свою ветку после каждого значимого шага (`wip(...)`): лимит API или
  перезапуск контейнера могут оборвать работу в любой момент. Не пушь.
- Каждый твой запрос перечитывает весь контекст, поэтому береги его:
  - большие файлы не читай целиком — сначала Grep, потом Read кусками по
    100–200 строк; не перечитывай файлы, которые уже правил;
  - картинку перед просмотром уменьши или обрежь (python/PIL или ffmpeg, не
    больше ~800 px по длинной стороне); одну картинку смотри один раз;
  - вывод команд — хвостом (`| tail -20`), логи Vite и тестов — только итог;
  - не держи больше одного Chromium одновременно: машина общая.
- Подробности по разделам игры — в `.claude/rules/*.md`; они подгружаются сами,
  когда ты открываешь файлы своей части.
- Prettier запускай только по файлам, которые создал сам или которые уже
  отформатированы (`npx prettier --check` сначала): `--write` по старому
  неформатированному файлу перепишет тысячи чужих строк.
- Перед сдачей: `npx tsc --noEmit -p .` и тесты своей части — зелёные.
