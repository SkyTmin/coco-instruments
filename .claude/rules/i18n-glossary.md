## Glossary — signature words in 7 languages (12.10.2026)

Owner: «use each language's jargon… fun, PRIMARY words natives get instantly». Rules for every
choice: a native gets it in a second (no obscure argot — the owner hates jargon he doesn't get,
so do players); no swear words, no slurs, no politics, no religion (store rules: Yandex Games,
App Store, Google Play); short (buttons — German runs ~30% longer). Keep the pun where Russian has
one (pets = animal + criminal trade). The interface renamings of `game-ui.md` hold in every
language (Лифт, Рюкзак, Торговец, Рабочие, Достижения, Навыки — never the old prison jargon).

Sources checked (curl, 12.10): de.wiktionary «Kalfaktor» (sense 5: «Gefangener, der … Hilfsdienste
für die Vollzugsbediensteten leistet»), «Knast», «Panzerknacker» («auf das Aufbrechen von
Panzerschränken spezialisierter Verbrecher»); tr.wiktionary «kodes» («argo, hapishane»), «kürek»
(shovel; oar); it.wiktionary «galera» (galley + «popolare: carcere»); fr.wiktionary «bagne»
(«lieu de travaux forcés»), «larbin» (populaire: domestique); es.wiktionary «recadero». Enchant
names follow the official Minecraft localisations players already know (Efficiency → Effizienz /
Efficacité / Eficiencia / Efficienza / Verimlilik; Fortune → Glück / Fortune / Fortuna / Servet);
rarity ladders follow the big mobile/PC games of each market (TR: Destansı, Efsanevi).
