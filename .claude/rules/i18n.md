## Translations — 7 languages (v2.x, 12.10.2026)

Owner: translate the game into EN, FR, TR, DE, ES, IT and translate every future update at once,
with fun words natives get instantly. Instruments (finance, notes, people, clothing, calculator)
stay Russian. Code: `src/i18n/`; words: `.claude/rules/i18n-glossary.md`.

- **Russian is the source.** `src/i18n/ru/<area>.ts` (`as const`); every other language
  `src/i18n/<lang>/<area>.ts` is typed `Translation<typeof ru>` — a missing key fails `tsc`.
  A new area goes into `ru/index.ts` and all six `<lang>/index.ts`.
- **Use:** `const t = useT()` in components (re-renders on switch), plain `t()` in toasts/canvas at
  the moment of showing. `t('a.b', { n })` picks the plural form by `n`; `{name}` placeholders,
  numbers in params are locale-formatted. `fmtNum` replaces the old local
  `toLocaleString('ru-RU')` helpers. `rich()` puts icons inside text. `upper/lower` are
  locale-aware (Turkish İ/ı); `<html lang>` follows the language so CSS casing is right too.
- **Plurals:** ru one/few/many/other; en/de/tr one/other; fr/es/it one/many/other (`many` =
  millions: «1 000 000 de pièces», «1.000.000 de monedas», «1.000.000 di monete»).
- **Lazy:** ru is in the main bundle, each other language is its own chunk (`LOADERS` in
  `core.ts`). Until the chunk arrives the UI shows Russian. Detection: saved choice
  (`localStorage['coco.lang']`) → Russian. Auto-detect (Telegram `language_code` →
  `navigator.languages` → English; aliases in `langs.ts`: kk/be/ky/tg → ru, az → tr,
  ca/gl/eu → es) is OFF by `AUTO_DETECT = false` (v2.143) until `NOT_YET_TRANSLATED` is empty —
  a non-Russian Telegram must not get a half-Russian game; a test enforces it. Settings hide
  the «Авто» row while it is off.
- **Guards** (`src/i18n/i18n.test.ts`): (a) same keys, same `{params}`, same text/plural kind, all
  plural categories of the locale, nothing empty, no Cyrillic outside ru; (b) no Cyrillic outside
  comments in game files (`src/pages`, `src/components`, `src/ui-px`, `src/game-shell`,
  `src/input`, `src/settings`, minus the frozen instrument list). `NOT_YET_TRANSLATED` only
  shrinks: a clean file must be removed from it, adding one fails. Cyrillic that is data, not UI →
  `// i18n-ignore` on that line.
- **Changing Russian text = changing six translations in the same commit.** No test can see that
  a translation went stale; the rule is the guard.
- **Data names** (pets, rocks, items…) live in `src/lib/*` in Russian for the logic and tests; the
  UI shows them through catalog keys by id — helpers in `src/i18n/data.ts` (`petName(id)`,
  `rockName(i)`, `blockName(i)`, `pickName(i)`, `rarityName(id)`, `enchantName(id)`,
  `itemName/itemText`, `runeName/runeText`, `streakName`, `chestName`, `crewName/crewText`,
  `perkName/perkText`, `horizonName`, `skinText(id, field)`). Data areas (`skins`, `pets`, `mine`)
  are GENERATED from the lib, and `i18n.test.ts` checks `ru.<area>` equals the lib text: rename a
  pet in `lib/pets.ts` → the test fails until `ru/pets.ts` and the six translations follow.
- `fmtShort(n)` replaces `shortMoney` in UI (ru «12,3 тыс.», en «12.3K», de «1,2 Mio.»).
- **Font:** `GxRubik` base file is Latin-1 + Cyrillic; `public/ui/fonts/rubik-ext.woff2`
  (Latin Extended-A: Turkish ş ğ ı İ, œ, €) is a second `@font-face` of the same family by
  `unicode-range` (in `src/settings/settings.css`). A new font must cover latin-ext too.

## Settings — `src/settings/` (same release)
- `<GameSettings onClose progress? initial? />`: tabs Language (globe, native names, «as in
  Telegram»), Sound (sound/music switches = synced `slotsSound/slotsMusic`; master/music/effects
  sliders = per device), Vibration (`slotsHaptics`), Display (UI scale auto/1×/2×/3×, text size,
  reduce motion), Controls (`settingsPanels.controls` — agent S plugs its bindings panel in),
  Progress (only when `progress` is passed: the mine passes its resets + cash desk, behaviour
  unchanged). Opened from the hall ⚙ and the mine ⚙.
- Device prefs: `useSettings` (localStorage `coco.settings.v1`), applied by `startSettings()`
  (`main.tsx`) to `<html>`: `data-ui-scale-pref`, `--ui-text`/`data-text`, `data-motion`;
  volumes → `setVolumes()` in `lib/sound.ts` (gain = slider², multiplies the bus levels; the
  `setMuted`/`setMusicOn` API is unchanged); vibration follows `slotsHaptics` globally.
- Layout: container query on the modal body — < 520 px icon tabs on top (they shrink, labels
  ellipsis), ≥ 520 px a rail on the left. Arrow keys move between tabs (gamepad via S's input).
