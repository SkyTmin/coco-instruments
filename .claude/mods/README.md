# Моды Claude Code

## cache-meter — кеш над полем ввода

Строка над полем ввода после каждого запроса к модели:

```
◆ кеш 171,3k  ↓168,2k чтение ↑3,1k запись  97% из кеша  · 4 мин назад  │ сессия ↓12,4M  │ агенты ↓2,1M
```

- «кеш» — сколько токенов лежит в кеше после последнего запроса главного диалога
  (прочитано + записано);
- «% из кеша» — какая доля запроса пришла из кеша (дёшево), остальное — полная цена;
- время с последнего запроса: зелёное до 5 мин, жёлтое до часа, красное дальше —
  кеш, скорее всего, остыл, и следующий запрос перепишет его по цене записи;
- «сессия» и «агенты» — сколько всего прочитано из кеша главным диалогом и подагентами.

Видно только в Claude Code в терминале и во вкладке Code приложения Claude Desktop
(локальная сессия). В облачной сессии и в мобильном приложении моды не рисуют.

Установка (Claude Code 2.1.287+):

```
git clone -b prod https://github.com/SkyTmin/coco-instruments.git
claude plugin marketplace add ./coco-instruments/.claude/mods
claude plugin install cache-meter@coco-mods --scope user
```

Проверка: `claude plugin validate .claude/mods/cache-meter`, тесты — `claude plugin test .claude/mods/cache-meter`.
