## Образцы (что откуда берём)

- **Minecraft**: железной киркой алмаз не добыть; книги чар; наковальня —
  две одинаковые книги дают уровень выше; кузнечный стол переносит чары на
  новую вещь.
- **Hypixel SkyBlock**: Breaking Power (руда выше силы кирки не ломается),
  редкость цветом имени (Common → Divine).
- **Terraria**: сила кирки % открывает руды; кирка из прошлой руды открывает
  следующую.
- **Stardew Valley**: кузнец — слитки + деньги → инструмент следующей ступени.
- **Присон-серверы (CosmicPE, VimeWorld, DiamondWorld)**: книги с шансом
  успеха, Чародей продаёт книгу яруса за опыт, Алхимик склеивает, пыль из
  ненужных книг поднимает шанс.
- **WoW / Archero / Genshin**: серый → зелёный → синий → фиолетовый →
  золотой; цвет вспышки заранее говорит редкость, вещь проявляется медленно.

## Решения

1. **Урона и заточки нет.** У кирки Сила ⛏ (какую руду берёт) и Скорость
   (блоков в минуту). Урон остаётся внутренней цифрой, в интерфейсе его нет.
   Скорость растёт от новой кирки и книги «Эффективность».
2. **Твёрдость руды.** Руда нового этажа не ломается старой киркой (звон,
   искры, «⛏10» в углу клетки). Рецепт кирки N — из руды, которую берёт
   кирка N−1, поэтому цикл всегда разрешим. Требует решения владельца.
3. **Семь редкостей**: Обычная (Ржавая–Кованая), Необычная (Железная–
   Кварцевая), Редкая (Опаловая–Лазуритовая), Эпическая (Гранатовая–
   Рубиновая), Легендарная (Алмазная, Звёздная), Мифическая (Родонитовая,
   Чароитовая), Божественная (Александритовая). Слоты книг 1…7. Визуал —
   рамка, свечение, блик, искры, лучи, аура; только transform/opacity.
4. **Экран кузницы** без «заказа»: кирка на пьедестале, рецепт
   [кирка]+[руда]+[монеты]→[новая], одна кнопка «Выковать». Руда для
   следующей кирки сама откладывается в ящик кузнеца при продаже рюкзака
   (как запас досок на рукоять). Чары переходят на новую кирку.
5. **Церемония выковки**: три удара → искры цвета редкости → вспышка с
   силуэтом → медленное проявление с именем цветом редкости.
6. **Чары — книги**: выпадают (блоки этажа, сундуки, посылки, мышь, король)
   и покупаются у Чародея — загадочная книга яруса за токены (черновик: 120 /
   500 / 2 000 / 8 000). Вписать — со шансом; не вписалась — сгорает книга, не
   кирка. Пыль из ненужных книг: +1% за штуку. Наковальня: две одинаковые →
   уровень выше, шанс — средний. Десять книг: Эффективность, Удача,
   Перековка, Кураж, Жила, Взрыв, Луч, Отбойник (только легендарная),
   Токенист, Ключник. Убираются Сила, Трещина, Камнепад, Эхо. Старые уровни
   чар превращаются в книги.
7. **Блоки этажа**: E–I 3, J–O 5, P–T 7, U–Y 10; попадаются раз в ~минуту;
   гарантия — 150 сломанных без блока этажа, следующий точно он; докупка
   втрое дороже блока.
8. **Лагерь → здания и нижняя панель** в шахте: Кузница · Книги · Сундуки ·
   Питомцы · Ещё (рабочие, руны, коллекция, достижения, навыки).
9. **Тот же язык** потом для топора/пилы, удочки, меча.
